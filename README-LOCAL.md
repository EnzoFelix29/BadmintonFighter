# 🏸 ระบบเก็บสถิติการแข่งขันแบดมินตัน — วิธีรันบนเครื่องของคุณเอง (localhost)

## สิ่งที่ต้องติดตั้งก่อน

1. **Node.js** เวอร์ชัน 20 ขึ้นไป → ดาวน์โหลดที่ https://nodejs.org (แนะนำรุ่น LTS)
   - เช็คว่าติดตั้งสำเร็จ: เปิด Terminal / Command Prompt แล้วพิมพ์ `node -v`
2. **npm** มาพร้อมกับ Node.js อยู่แล้ว (ไม่ต้องติดตั้งเพิ่ม)

## ขั้นตอนการรัน (4 ขั้นตอน)

```bash
# 1. แตกไฟล์ zip แล้วเข้าไปในโฟลเดอร์โปรเจกต์
cd badminton-app

# 2. ติดตั้ง packages ที่จำเป็น (รอสักครู่ ~1-2 นาที)
npm install

# 3. สั่งรันเซิร์ฟเวอร์
npm run dev

# 4. เปิดเบราว์เซอร์แล้วเข้าไปที่
#    http://localhost:3000
```

เท่านี้ก็ใช้งานได้แล้ว! 🎉 — **ไม่ต้องตั้งค่าอะไรเพิ่ม ไม่มีรหัส PIN ไม่มีฐานข้อมูล**

## 🗄️ ข้อมูลเก็บที่ไหน?

- ข้อมูล**ทั้งหมดเก็บใน localStorage ของเบราว์เซอร์** (เครื่องนี้ เบราว์เซอร์นี้ เท่านั้น) — ปิดแท็บ/ปิดเครื่องแล้วข้อมูลยังอยู่
- แมตช์ + ตารางอันดับ: key `badminton_matches`, `badminton_teamStats`
- ผู้เล่น + เหรียญ + สกิน: key `badminton_players`
- โหมดจอที่เลือกไว้ (แนวตั้ง/แนวนอน): key `badminton_display_mode`
- **ข้อจำกัด**: ข้อมูลไม่แชร์ข้ามเครื่อง — ถ้าเปิดจากเบราว์เซอร์/คอมอีกเครื่องจะเห็นข้อมูลว่างเปล่า (แยกกัน)

## ✨ วิธีใช้งาน (ไม่มี PIN แล้ว — ใช้ได้เลยทุกอย่าง)

- **ลงทะเบียนผู้เล่น**: กดปุ่ม "ผู้เล่น" → พิมพ์ชื่อ → กดลงทะเบียน จบเลย (ไม่ต้องตั้งรหัส)
- **บันทึกผลแข่ง**: เลือกชื่อผู้เล่น ใส่คะแนน กดบันทึก — ทีมชนะ +7 เหรียญ/คน ทีมแพ้ +3 เหรียญ/คน
  - **ชนะขาด** = ฝ่ายแพ้ได้แต้มต่ำกว่า 5 แต้ม หรือคะแนนห่างกัน 15 แต้มขึ้นไป → ทีมชนะได้ **+10 เหรียญ/คน** แทน
- **กฎกติกา**: กดปุ่ม "กฎกติกา" บนแถบด้านบน — สรุปวิธีได้เหรียญ พร้อมตัวอย่างคะแนนจบเกม (อ่านง่าย เหมาะสอนเพื่อนใหม่)
- **แท่นรับเหรียญรางวัล**: หน้า "สรุปภาพรวม" มีแท่นอันดับ 1-3 (ทอง/เงิน/ทองแดง) เรียงตาม Win Rate — อยู่ในรูปที่กด "เซฟเป็นรูป" ด้วย
- **โหมดจอแนวตั้ง/แนวนอน**: กดสวิตช์ "แนวตั้ง / แนวนอน" บนแถบด้านบน — แนวตั้ง = เรียงคอลัมน์เดียวแบบมือถือ, แนวนอน = ฟอร์มกับตารางอันดับอยู่คู่กันแบบจอกว้าง (จำค่าที่เลือกไว้ ถ้ายังไม่เคยเลือกเองจะสลับตามการหมุนจอของเครื่องอัตโนมัติ)
- **เปลี่ยนสกินตัวละคร/ไม้แบด/รองเท้า**: กดช่องอวตารของผู้เล่นคนนั้น → เปิดตู้ Reel ทันที
- **ร้านค้า**: สกินพิเศษ 100 เหรียญ/สกิน — ปลดล็อคด้วยเหรียญของผู้เล่นคนนั้น
- **ล้างข้อมูลสถิติ**: กดปุ่ม "ล้างข้อมูล" → ยืนยันหนึ่งครั้ง (แมตช์+ตารางอันดับหายหมด, โปรไฟล์/เหรียญ/สกินยังอยู่)
- **ลบผู้เล่น**: ในหน้า "ผู้เล่น" กดปุ่มถังขยะ → ยืนยันหนึ่งครั้ง

## หยุด / รันใหม่

- **หยุดเซิร์ฟเวอร์**: กด `Ctrl + C` ใน Terminal
- **รันครั้งหน้า**: เข้าโฟลเดอร์โปรเจกต์แล้วพิมพ์ `npm run dev` ได้เลย (ไม่ต้อง `npm install` ซ้ำ)

## หมายเหตุ

- ถ้า port 3000 ถูกใช้งานอยู่ ให้รันแบบกำหนด port เอง เช่น `npm run dev -- -p 3001` แล้วเข้า http://localhost:3001
- รองรับโหมดกลางวัน/กลางคืน (Light/Dark) กดสลับได้ที่ปุ่มบนหน้าเว็บ
- อยากสำรอง/ย้ายข้อมูลไปเครื่องอื่น: เปิดหน้าเว็บ → DevTools (F12) → Application → Local Storage → ก๊อปทุก key ที่ขึ้นต้น `badminton_` ไปวางที่เครื่องใหม่ได้
